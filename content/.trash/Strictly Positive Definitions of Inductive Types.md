# Strictly Positive Definitions of Inductive Types
---
Defining new inductive types is one of the most important aspect of type theory, and as the name suggests, elements of such a type are supposed to be constructed by using other elements itself with the help of constructors:

This we will treat the constructor as an endofunctor on the type of elements, for this to make sense, and for one to be able to construct a function out of this type, it is required to be able to apply the functions to the simpler elements of the type, on which the constructor is applied. 

A non-example would be a type $C$ generated by the constructor:
$$
g:(C \to \mathbb{N}) \to C
$$
The recursion principle for such a type would mean that one only needs to define a function on all functions from $C \to \mathbb{N}$. 

That is, to define $f:C \to D$, one only needs to assume that the inputs are of the form $g(\alpha:C\to \mathbb{N})$. But it is not clear how one would use $f$ to construct the function for $\alpha$. 

To avoid this, we put a restriction on the functions are allowed to be used as inputs. The above issue was caused because $C\to \mathbb{N}$ is contravariant in $C$. But putting the restriction of covariance on the constructor is not enough, because $(C\to \mathbb{N})\to \mathbb{N}$ now becomes covariant but the constructor still does not input elements of $C$.

This we put the restriction of having all references of the inductive type in strictly positive. That is each argument of the constructor either does not involve the type that is constructed, or has it in its codomain.

Oh, strict positivity implies the strong normalization property
