# Postnikov construction of truncated types
---
Given any type $A:\cal U$, consider the [[Higher Inductive Types|higher inductive type]] generated by the following:
- a function $|-|_{n}:A\to\|A\|_{n}$,
- For each $r:\mathbb S^{n+1}\to\|A\|_{n}$, a hub point $h(r):\|A\|_{n}$
- For each $r:\mathbb S^{n+1}\to\|A\|_{n}$ and each $x:\mathbb S^{n+1}$, a spoke path $s_{r}(x):r(x)=h(x)$.

>[!lemma]
>$\|A\|_{n}$ is an $n$-type.

By [[A type X is an n+1 type iff loop space is an n type]], we need to show that $\Omega^{n+1}(\|A\|_{n}, b)$ is contractible for all $b:{\|A\|}_{n}$ which is equivalent to $\text{Map}_{*}(\mathbb S^{n+1}, (\|A\|_{n}, b))$. As the center of contraction for the latter we pick $c_{b}:\mathbb S^{n+1}\to\|A\|_{n}$ which is constant at $b$ with $\text{refl}_{b}:c_{b}(\text{base})=b$.

Let $r:\mathbb S^{n+1} \to \|A\|_{n}$ together with the  path $p:r(\text{base})=b$. By function extensionality, we show that $r=c_{b}$, we have $r(x)=c_{b}(x)\equiv b$. We choose this to be the composite $s_{r}(x)\cdot s_{r}(\text{base})^{-1}\cdot p$ where $s_{r}(x)$ is the spoke at $x$.

Now we show that when transported along $r=c_{b}$, the path $p$ becomes $\text{refl}_{b}$ but by transport of paths we get
$$
(s_{r}(\text{base})\cdot s_{r}(base)^{-1} \cdot p)^{-1}\cdot p = \text{refl}_{b}
$$
And this is trivial.

>[!note] Induction Principle
>Given a type $P:\|A\|_{n} \to \cal U$ together with 
>- For each $a:A$, an element $g(a):P(|a|_{n})$,
>- For each $r:\mathbb S ^{n+1} \to\|A\|_{n}$ and $r': \prod_{(x:\mathbb S^{n+1})}P(r(x))$ an element $h(r,r'):P(h(r))$.
>- For each $r:\mathbb S^{n+1}\to\|A\|_{n}$ and $r':\prod_{(x:\mathbb S^{n+1})}P(r(x))$, and each $x:\mathbb S^{n+1}$, a dependent path $r'(x)=_{s_{r}(x)}^P h'(r, r')$.
>
>there exists a function $f:\prod_{(x:\|A\|_{n})}P(x)$ with $f(|a|_{n})\equiv g(a)$ for all $a:A$.
