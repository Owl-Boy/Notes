# Paths in a graph
---
>[!definition] 
> Let $X$ be a graph and $x, x':X$.
> A *path* $\gamma : x \squigrightarrow x'$ of length is is a map $gamma :I_n \to X$ such that $gamma(0) = x$ and $gamma(n)=x'$.

Fairly straightforward notation concepts that can be defined :
- Constant path 
- Concatenation of paths 
- Inverse path 
- Path connectedness
