# Hilbert's Basis Theorem
---
>[!theorem]
>$$
>R \text{ is Noetherian} \Rightarrow R[x]\text{ is Noetherian}
>$$

Let $I$ be an ideal of $R[x]$, we need to show that this is finitely generated. 
Consider the set 
$$
A = \{ 0 \} \cup \{ a\in R \mid a \text{ is a leading coefficient of an element of }I\}
$$
This is an ideal in $R$, so is finitely generated by elements $\langle a_{1},a_{2}\dots a_{m}\rangle$, which are leading coefficents of polynomials $f_{1},f_{2}\dots f_{m}$. Let $d$ be the maximum degree among these polynomials so consider the sub-module:
$$
M=\langle 1,x,x^2\dots x^{d-1}\rangle \subseteq R[x]
$$
Since [[If R is noetherian and M is finitely generated then M is noetherian]], we have that $M$ is [[Noetherian Modules|noetherian]].

So $M \cap I$ form a sub-module of $M$ and are hence finitely generated by $g_{1},g_{2},\dots g_{n}$.

We now claim that $I=(f_{1},f_{2},\dots f_{m},g_{1},g_{2}\dots g_{n})$.

This is clearly a subset of $I$ so we need to show inclusion.

Consider a polynomial $\alpha\in I$. If degree $\alpha(x)\geq d$, let $a$ be the leading coefficient. We know what $a\in A$, so we can find $b_{1},\dots b_{r}$ such that
$$
a=b_{1}a_{1}+b_{2}a_{2}+\dots+b_{r}a_{r}
$$
Thus we can use the polynomials $f_{1}\dots f_{m}$ to generate a polynomial with the same degree and leading coefficient as $\alpha$. so we can product a smaller polynomial by subtracting it.

We do this until we can get a polynomial whose degree is smaller than $d$ and we will be able to generate it using $g_{1},g_{2}\dots g_{n}$. So we are done.
