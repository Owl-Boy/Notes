# Elementary Topos

> [!DEF]
> An **Elementary Topos** is a category $C$ such that:
> - It has all finite limites
> - It has all finite colimits
> - It has exponential objects
> - It has a sub-object classifier

C. Juul Mikkelsel proved that point 2 can proved using the others and is hence omitted in most definitions.

Points 1 and 3 define a [[Cartesian Closed Category]], So an alternative definition can be:

>[!Def]
> An Elementary topos is a cartesian closed category with a sub-object classifier.
