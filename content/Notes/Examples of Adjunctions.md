#  Examples of Adjunctions
---
>[!example]
>The following pairs of functors form an adjunction between the category of sets and the category of $\mathbb k$-vector spaces:
>$$U \vdash F$$
>That is, the forgetful functor $U:\text{Vec}_{\mathbb k}$ is the right adjoint to the free functor $F:\text{Set} \to\text{Vec}_{\mathbb k}$ that sends a set $S$ to the vector space with the set $S$ as its basis.

>[!example]
>The forgotful functor $F:\text{Top}\to\text{Set}$ admits both adjoints.
>The left adjoint constructs a topological space such that given a set $S$ and a topological space $T$, we have that $G(S)\to T$ naturally bijects with $S\to U(T)$. This means that any set function from $S\to U(T)$ would correspond to a  continuous function $G(S)\to T$ so we are forced to make $G$ the discrete functor.
>For the right adjoint construction, given a topological space $T$ and a set $S$ there is a natural bijection between the functions $U(T)\to S$ and $T\to G(S)$. So we want all incoming set functions into the topology generated by $S$ to be continuous, which is a property satisfied by the indiscrete topology.

>[!example]
>A propositional function $P:X\to\mathbb B$ takes an element of a set $X$ and assigns it $\top$ or $\bot$.
>We define $\Omega^X$ as the set of propositional functions on $X$, and this set can be given the preorder where we say $\top>\bot$ and a componentwise pre-order.
>The logical quantifiers also define functions:
>$$
>\forall_{X},\exists_{X}:\Omega^X\rightrightarrows \Omega 
>$$
>In the obvious way.
>There is also a function $\Delta_{X}:\Omega\to \Omega^X$, which defines a dummy variable. We then get that the follwing functions are adjoints of each other.
