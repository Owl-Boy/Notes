# Identity Types form an Inductive Family
---
[[Identity Type]] form an inductive family of types with an index as defined in [[Some Generalization of Inductive Datatypes#Inductive Family of Types]]. 

There are 2 ways to represent identity type leading to the 2 different inductive types [[Path Induction]] and [[Based Path Induction]], and in both cases $A$ is a parameter.

For the first one we define the family inductively as follows:
$$
=_{A}: A \to A \to \cal U
$$
where the base cases are for all $a:A$
$$
refl_{a}:a=_{A}a
$$
And to extract the induction principle, we simply get that it suffices to give a proof for $\text{refl}_{a}$ for all to define a function on all identity types.

For the second definition, we simply define the family by fixing $a_{0}$, and the rest is similar.

This seems rather odd if we see types as sets, where when we want to generate a set given a starting element and some operations, the sets generated should precisely be whatever are created by applying the operators to the elements of the set. This is not in general true for other structures like groups where a group generated by 1 element and no extra operator is still an infinite sets. That is because of the ambient group operation.

Here we have operations on paths because our ambient structure is that of an infinite groupoid. On top of that, all functions are functorial because of the induction principle, that would include all type families, specifically $a_{0}=_{A}- : A \to\cal U$. This makes the indentity type a freely generated functor generated by the element $\text{refl}_{a_{0}=a_{0}}$.

We also get by [[Yoneda Lemma]] that a functor which is freely generated $a_{0}:A$ by an element is naturally isomorphic to $\text{hom}_{A}(a_{0},-)$. This we treat the type $a_{0}=-$ as a functor represented by $\text{refl}_{a_{0}}$.
