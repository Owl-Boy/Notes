# Theory of torsion-free divisible Abelian Groups is $\kappa$ categorical for uncountable $\kappa$
---
The theory of torsion free abelian groups is the theory of abelian groups with the following extra axioms:

$$
\forall x(x\ne 0 \to \underbrace{x+\dots+x}_{n-\text{times}}\ne 0)
$$

for each $n$. This states that all elements are torsion free.

$$
\forall y\exists x\; \underbrace{x+\dots+x}_{n-\text{times}}=y
$$
which is the divisibility condition. Let this theory be named $T$.

> [!THM] Theorem 
> The theory $T$ is $\kappa$-categorical for all $\kappa > \aleph_0$.

Note that any vector space over the field $\mathbb Q$ is a torsion free divisible subgroup.

Otherwise, consider any model $G$ for $T$. Since $G$ is torsion-free, for each $g$, there is a unique element $h$ such that $nh=g$. Let that element be $g/n$, then we can uniquely construct $\frac mn g$

Thus model of $T$ are isomorphic up to dimension.

if $G$ is uncountable, then the set of basis has the cardinality has $G$ thus we get that $T$ is isomorphic upto do cardinality.
