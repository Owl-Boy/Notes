# Representable Functors
---
>[!definition]
>A **Representation** of a functor $F$ is a choice of object $c \in C$ with a specified choice of natural isomorphism $C(c, -)\cong F$, if $F$ is covariant and $C(-,c)\cong F$ if $F$ is contravariant.
>We say $F$ is is a **Representable** functor from a locally small category  $C \to \text{Set}$ if there an object $c\in C$ and a natural isomorphism between $F$ and the functor represented by $c$, in which case one can say $F$ is represented by $c$.

These functors can be used to express properties about objects on a category in a categoricaly way.
