# First Cycle Mean Payoff Games
---
**First Cycle Mean-Payoff Games** are finite version of [[Mean Payoff Games]].

In a first cycle mean-payoff game the play ends as soon as a vertex is repeated twice. Thus making the game finite. The value of the game is the value of the cycle.
