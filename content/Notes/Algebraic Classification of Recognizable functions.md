# Algebraic Classification of Recognizable functions
---
>[!theorem]
>A function $f$ is [[Weighted Automata|recognizable function]] over $\mathbb S\langle\!\langle \Sigma^*\rangle\!\rangle$ iff $f\in M$ for some stable and finitely generated left-submodule $M$ of $\mathbb S\langle\!\langle \Sigma^*\rangle\!\rangle$.

**Right $\rightarrow$ Left**
If a function is in a finitely generated submodule $M$:
- Let $\mathcal G$ be the set of generators, and we know that every other element can be written as a "linear" combination of these elements. For each element in $\mathcal G$, make a state.
- Now for each $g\in \mathcal G$, we quotient the function with a character to get another function, which is in the span of $\mathcal G$. This gives the transitions of the letter. Do the same for every letter in the alphabet.
	- This process is well defined because $M$ is stable.
- Now we write each function $g$ the weighted automata by taking the transition table constructed above and for the input vector the automata for $g_{i}$ is $[0\dots 0, {1}, 0\dots {0}]$ where $1$ is in the $i^\text{th}$ index.
- Running this automata on the word will give a linear combination of $g_{i}(\epsilon)$, so for the final state we have $[g_{1}(\epsilon),g_{2}(\epsilon)\dots g_{n}(\epsilon)]$.
- Any other automata can be made by a linear combination of these automata.

**Left $\to$ Right*** 
For this one, given a weighted automata $A$ for the function, let $A_{i}$ be the automata $A$ with the initial vector replaced with $[0 \dots 0,1,0 \dots 0]$ where $1$ is in the $i^\text{th}$ index.

This gives me $n$ functions which will be the generators of my set.

The transition table gives the quotients of the functions and hence shows that the space is also stable.

The space generated by the set also trivially contains the automation $A$, so we are done.
