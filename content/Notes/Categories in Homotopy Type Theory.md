# Categories in Homotopy Type Theory

---
*Category Theory* is perhaps the branch of mathematics where set theory fits the least comfortably while trying to define an objects because its notion of equality is too strict. Making Equality and Equivalence agree is precisely the problem that the [[Univalence|Univalence Principle]] solves.

There are 3 distinct notions of categories in Homotopy Type Theory:
- *Strict Categories*: Type of objects and morphisms are sets.
- *Pre-categories*: The Naive conversion from set theory to type theory.
- *Categories*: Imposing the type of isomorphism to be the same as the type of equalities. This is considered as the more "correct" implementation.

The distinction between the following 3 definition is seen in how one they interact with the statement "An equivalence is a fully-faithful essentially surjective functor".
- *Strict Categories*: This is equivalent to Choice
- *Pre-categories*: This is statement is not true in general.
- *Categories*: This statement is probable constructively.
