# Ring Homomorphisms
---
**Ring Homomorphisms** are the favourite kinds of maps of rings.
>[!definition]
>A **Ring Homomorphism** from between rings $\phi: A \to B$ is a function which satisfies the following properties
>- $\phi : 0_{A} \mapsto 0_{B}$
>- $\phi : 1_{A} \mapsto 1_{B}$
>- $\phi(a + b) = \phi(a) \oplus \phi(b)$
>- $\phi(a \cdot b) = \phi(a) \odot \phi(b)$
