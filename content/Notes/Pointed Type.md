# Pointed Type
---
>[!definition]
>A *Pointed type* ,$(A,a)$ is a type $A$ along with an element of it $a:A$ which is called its *base point*.

We write 
$$
\mathcal U_{\bullet} :\equiv \sum_{A:\mathcal U}A
$$
for the type of pointed types in the universe $\cal U$.
