# Expression Complexity of a Logic
---
**Expression Complexity** captures how hard it is, given a model, to match expressions given in the logic to given model. It captures the complexity of the model checking problem introduced by the queries themselves and is described as:

>[!definition]
>The expression complexity of a logic $\mathcal{L}$ is $\cal K$ if for every finite model $\mathfrak A$, the language
>$$
>\{ \text{enc}(\Phi)\; | \; \mathfrak A \vDash \Phi \}
>$$
>belongs to $\cal K$.
