# PTAS
---
>[!definition]
>*Polynomial Time Approximation Scheme* is class of problems such that for any $\epsilon$, there is a polynomial time algorithm that guarantees a $1+\epsilon$ approximate solution.

>[!theorem]
>$\text{PTAS} \subseteq \text{APX}$ and the we have that $\text{PTAS}=\text{APX}$ iff $\text{P}=\text{NP}$
