# Sphere
---
>[!definition]
>The 2-sphere $\mathbb S^2$ is the [[Higher Inductive Types|higher inductive type]] generated by:
>- A point $\text{base}:\mathbb S^2$
>- A 2-dimensional path $\text{surf}:\text{refl}_{\text{base}}=\text{refl}_{\text{base}}$ in $\text{base}=\text{base}$.

The recursion principle is not hard
>[!note] Recursion Principle
>To define a functions $f:\mathbb S^2\to A$ we need $A$ to:
>- have a point $a:A$
>- a path $s:\text{refl}_{a}=\text{refl}_{a}$
>
>such that $f(\text{base})\equiv a$ and $\text{ap}^2(\text{surf})=s$.

Induction principle uses some statements about a higher dimensional functorial behaviour of functions : [[Functions as Functors of 2 Category]].

>[!note] Path Induction
>Given $P:\mathbb S^2\to\cal U$ with $b:P(\text{base})$ and $s:\text{refl}_{b}=_{\text{surf}}^Q\text{refl}_{b}$ where $Q:\equiv\lambda p.b=_{p}^Pb$. Then there is a function $f:\prod_{x:\mathbb S^2}P(x)$ such that $f(\text{base})\equiv b$ and $\text{apd}^2_{f}(\text{surf})=s$.

For any higher dimensional sphere we define it as 
>[!definition]
>- A point $\text{base}:\mathbb S^n$
>- An $n$-loop $\text{loop}_{n}: \Omega^n(\mathbb S^n, \text{base})$

And the recursion and induction principles are defined according with higher level notions of $\text{ap}$ and $\text{apd}$.
