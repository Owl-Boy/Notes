# Some Monadic functors
---
Using [[Monadicity Theorem]], the following free $\dashv$ forgetful adjunctions can be shown to be monadic. 
- [[Monoids]]
- [[Groups]]
- [[Ring|Rings]]
- [[Abelian Groups]]
- [[Modules]]
- Vector Spaces
- Affine Spaces
- [[Lattice]]
- Meet or Join semi lattice
- Pointed sets.
