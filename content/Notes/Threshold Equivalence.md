# Threshold Equivalence
---
>[!definition]
>Given 2 structures $\mathfrak A$ and $\mathfrak B$ in a relational vocabulary, we write $\mathfrak A \leftrightarrows^\text{thm}_{d, m}$ if for every isomorphism type type $\tau$ of a $d$-neighbourhood of a point, either:
>- Both $\mathfrak A$ and $\mathfrak B$ have the same number of points that $d$-realize $\tau$,or 
>- Both $\mathfrak A$ and $\mathfrak B$ have at least $m$ points that $d$-realize $\tau$.
>

>[!tip] Intuition
>If we allow $m$ to be $\infty$, then we just get the direct $\mathfrak A \leftrightarrows_{d} \mathfrak B$. This definition lets us only care about the bijection if the number of points that realize the same isomorphism types are small enough. 
>
>The intuition behind this is that, between 2 structures, we would like to be able to make bijection between points that realize the same isomorphism type, but our formula can only look at so many things in the locality. So it is okay if there are enough elements that realize an isomorphism class for a partial isomorphism between the structures.
