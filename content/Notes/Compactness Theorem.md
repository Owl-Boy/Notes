# Compactness Theorem
---
Let the set of all complete $L$ theories be denoted by $S_L$.

Given $\varphi\in L_0$, let $\langle \varphi \rangle =_\text{def} \{T\in S_L : T\models \varphi\}$. We see that $\langle \varphi\rangle\cap \langle\psi\rangle =\langle \varphi\land\psi\rangle$.

Thus consider the topology generated by the basis $\{\langle\varphi\rangle : \varphi\in L_0\}$ on $S_L$.

These open sets are also closed, as $\langle\varphi\rangle^C=\langle\lnot\varphi\rangle$. Since $S_L$ has a basis of clopen sets it is also hausdorff, since for all $T, T'\in S_L$. If $T\ne T'$ then there is a formula $\varphi$ such that $T\models\varphi$ but $T'\not\models\varphi$. Thus $T\in\langle \varphi\rangle$ and $T'\in\langle\lnot\varphi\rangle$.

> [!THM] Theorem 
> The space $S_L$ defined above is [[Compactness|compact]] and hence also a [[Stone Spaces]].

Suppose $S_L=\bigcup_{i\in I} U_i$ is a covering such that $U_i=\bigcup_{\varphi\in\Sigma_i}\langle\varphi\rangle$ for $\Sigma_i\subseteq L_0$.

We have 
$$
\emptyset = S_L\setminus \bigcup_{i\in I} U_i= S_L\setminus\bigcup_{\varphi\in \Sigma}\langle\varphi\rangle = \bigcap_{\varphi\in\Sigma}S_L\setminus\langle\varphi\rangle = \bigcap_{\varphi\in\Sigma}\langle\lnot\varphi\rangle
$$

This means that the set of sentences has no model. Thus given the set $\Sigma$, one can find finitely many formulas from it that do not have model. Let that set be $\lnot \varphi_1,\lnot\varphi_2\dots\lnot\varphi_n$.

Thus we get 
$$
S=\bigcup_{i\in[1,n]}\langle\varphi_i\rangle
$$

hence the space is compact.
