# Weakly initial objects and joint weakly initial sets
---
>[!definition]
>- An object $c$ in category $C$ is called **weakly initial** if for every $x\in C$, there is a morphism $c\to x$ (which might not be unique).
>- A collection of objects $\Phi=\{ c_{i} \}$ is a category $C$ is called **jointly weakly initial** if for every $x\in C$, there exists some $c_{i}$ for which there exists a morphism $c_{i}\to x$.
