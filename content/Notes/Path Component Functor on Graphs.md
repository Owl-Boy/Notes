# Path Component Functor on Graphs
---
The Path component functor $\pi_0$ takes a graph and sends it to its set of path-component. This functor is the left-adjoint to the discrete functor making the following diagram.

![pc_functor_adjunction.png](Attachments/pc_functor_adjunction.png)
We also have that $\pi_0( X \otimes Y) = \pi_0 X \times \pi_0 Y$

This makes this a [[Monoidal Functor]].
