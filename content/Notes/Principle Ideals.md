# Principle Ideals
---
>[!definition]
>A **Principal Ideal** is an [[Ideals]] that is generated by a single element. i.e we call an ideal $I$ a **Principle Ideal** if there exists an element $a\in R$ such that:
>$$
>I = RaR
>$$
>The notation for an ideal generated by $a$ is $(a)$

One can generalize the notion of an *Ideal* being generated by elements, to do so one wants to consider the smallest ideal containing a set of elements, this can be defined as follows:
$$
(a_{1},a_{2} \dots a_{n}) = (a_{1}) + (a_{2}) \dots (a_{n})
$$
An Ideal $I$ is called **Finitely Generated** if there is a finite set $A$ such that $I$ is generated by elements of $A$.
