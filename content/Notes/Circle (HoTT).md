# Circle
---
>[!definition]
>We define the circle as the [[Higher Inductive Types]] generated by:
>- A point $\text{base}:\mathbb S^1$ and
>- A path $\text{loop}:\text{base}=\text{base}$

>[!note] Recursion Principle
>The recursion principle of the circle states that if there is a type $B$ with
>- A point $b_{0}:B$
>- A path $p:b=b$
>Then there is a function $f$ such that $f(\text{base})=b_{0}$ and $f(\text{loop})=\text{p}$.

>[!note] Induction Principle
>The induction principle states that given $P:\mathbb S^1\to\cal U$ with
>- $a:P(\text{base})$
>- a path $p:a=_{\text{loop}}^{x\mapsto P(\text{base})}$ such that 
>Then there is a function $f:\prod_{(x:\mathbb S)}x\to P(x)$ that sends $x$ to $a$ and $\text{loop}$ to $p$
