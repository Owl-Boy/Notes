# Minimum Spanning Trees
---
>[!question] The Problem
>Given a connected undirected graph $G$ with a weight function $w$ to the edges, a minimum spanning tree is a sub-graph $T$ of $G$ such that $T$ is a tree and any other sub-tree of $G$ has sum of weights greater than or equal to that of $T$.

There are a lot of applications for minimum spanning trees which include:
- Telecommunication companies laying cable in a new neighbourhood
- Taxonomy
- Cluster Analysis
