# Kleisli Category and Eilenberg Moore Category in the Category of Adjunctions
---
>[!theorem]
>The [[Kleisli Category]] $C_{T}$ is the initial object in [[Category of Adjunctions]] and the [[Eilenberg Moore Category]] $C^T$ is terminal, that is for any adjunction $F\dashv U$ the following exists:
>![[Pasted image 20250816170116.png|200]]

Let $\epsilon:FU \Rightarrow 1_{D}$ for the counit for $F\dashv U$. Hypothesis states that $U\epsilon F=\mu$.

On an object $c\in C_{T}$ we can define $Jc=Fc$ so $JF_{T}=F$. Consider a morphism $f:c\rightsquigarrow c'$ in $C_{T}$, we have that given its image, applying the functor $U$ to it it gives the same as $f:c-Tc'$ so we are forced to define
$$
Jf:=Fc\xrightarrow {Ff} FUFc' \xrightarrow {\epsilon F_{c'}}Fc'
$$
This defines the functor $J$.

Now to define the functor $K$. Take an object $d$ in $D$. we have that $Ud=U^TKd$. Since given any $(c, \gamma:Tc\to C)$ has $\gamma$ a.s a map to $c$ from the free algebra generated by it, thus we can think of the morphism $\gamma:(Tc, \mu_{c})\to (c, \gamma)$ from the free $T$-algebra on $c$ to the given $T$-algebra that is the transpose of the identity on $c=U^T(c, \gamma)$ so we should define $Kd=(Ud, U\epsilon_{d})$, we now need to show that $U\epsilon_{d}:UFUd\to Ud$ is an algebraic structure which uses the fact that $U\epsilon F=\mu$.
