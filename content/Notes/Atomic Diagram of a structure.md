# Atomic Diagram of a structure
---
If $\mathcal M$ is an $L$-structure. Let $L_\mathcal M$ be the extension of $L$ where for each element of $M$ we had a constant symbol to $L$. 

> [!DEF]
> The **Atomic diagram** of $\mathcal M$ is the set of formulas $\varphi(m_1,\dots,m_n)$ such that $\varphi$ is either an atomic formula, or is the negation of an atomic formula such that $\mathcal M\models\varphi(m_1,\dots,m_n)$

If we allow $\varphi$ to be any formula, then we call it the elementary embedding.
