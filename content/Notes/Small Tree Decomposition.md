# Small Tree Decomposition
---
A [[Tree Decomposition]] $\mathcal T = (T, B_{*})$ is called small if for all $t \neq t'\in T$ we have $B_{t'}\neq B_{t}$.
>[!note]
>It is enough to show that for no two neighbours in $\cal T$ they have bags which are subsets of each other. Because if $A \subseteq B$ then for all vertices in the path from $A$ to $B$, the bags will contain $A$.
