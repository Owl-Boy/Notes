# Duality Theorems for LP
---
>[!theorem] Weak Duality
>The weak duality theorem states that for each feasible solution $x$ if the primal linear program, and each feasible solution $y$ of the dual program we have $x c^T \leq b^T y$, that is, an objective value of the feasible solution for dual is an upper bound of objective values of the primal and any objective value of the primal is a lower bound of the objective values of the dual.

>[!theorem] Strong Duality
> The strong duality theorem states that if one of the 2 programs has the optimal solution, then so does the other, and on those optimal solutions the bounds would be tight:
>$$\max_{x} c^T x = \min_{y} b^T y$$
