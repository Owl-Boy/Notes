#  Example of Atomless Boolean Algebra
---
> [!EXAMPLE] Logical Proposition
> Let there be a countably infinite set of atomic proposition. Consider the set of equivalence classes under logical equivalence of propositional formulas.
> This gives a partial order, which is also a boolean algebra (literally og boolean algebra).
> Given any element $\phi$, let $p$ be an atomic proposition not used in $\phi$, then the formula $\phi\land p$ is smaller than $p$ and is not $\bot$. 
> Thus there are no atoms in this algebra.

> [!EXAMPLE] Measure
> This will work with other measure spaces too but I will just be using the real one.
> Consider 2 measure sets equivalent if their symmetric difference is almost empty. This forms a boolean algebra under union, intersection and complementation.
> Any almost empty set is equivalent to $\bot$. Thus it cannot be an atom.
> Any set with non-zero measure will have a subset of smaller measure, thus will also not be an atom. Thus, there are no atoms.
