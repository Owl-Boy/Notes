# Fully Faithful Functors and Adjunctions
---
Consider the following adjunction:
![[Pasted image 20250714171431.png|150]]

with counit $\epsilon:FG\Rightarrow 1_{D}$ then
>[!theorem]
>- $G$ is faithful iff each component of $\epsilon$ is an epimorphism.
>- $G$ is full iff each component of $\epsilon$ is an monomorphism.
>- $G$ is fully faithful iff each component of $\epsilon$ is an isomorphism

And dually, with unit $\eta:1_{C}\Rightarrow GF$:
>[!theorem]
>- $F$ is faithful iff each component of $\epsilon$ is an monomorphism.
>- $F$ is full iff each component of $\epsilon$ is an epimorphism.
>- $F$ is fully faithful iff each component of $\epsilon$ is an isomorphism
