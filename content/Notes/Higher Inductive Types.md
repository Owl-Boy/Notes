# Higher Inductive Types
---
**Higher Inductive Types** are a general schema for defining new types using constructors. But unlike ordinary [[Inductive Types]], we have constructors to generate [[Identity Type|Paths]].

Since [[Types are Higher Groupoids|Higher Groupoids]], are multi-sorted objects, we have a multi-sorted collection of constructors. The ordinary sort of constructors are called *point constructors* while the others are called *path constructors* or *higher constructors*. A path constructor must specify its source and target.

Some points:
- The word *generation* should be taken seriously in the same sense as a group can be freely generated. The generated elements are not already existing members of the set a-priori, neither are the elements generated by composition and inversions of such paths.
- The the generations are *free* generations: These generations do not allow us to impose restrictions like $\text{loop}\cdot\text{loop}=\text{refl}_{\text{base}}$. However a later restriction can be added like a path between the 2 paths.
- Higher inductive types contain constructors which generate paths in the type, it is still an inductive definition of a single type.
- The dimension of the constructor does not have a direct connection with the dimension in which the higher homotopy group is non-trivial.
