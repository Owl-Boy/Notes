# Set Pushout
---
>[!theorem]
>Let $A\xleftarrow f C\xrightarrow g B$ be a span of sets. Then for any set $E$, there is a canonical equivalence
>$$
>\left(\left\|A\sqcup^C B\right\|_{0}\to E\right)\simeq \text{cocone}_{\cal D}(E)
>$$

The proof us just a composition of the equivalences discussed in [[Universal Property of Set Truncations]] and [[Universal Property of Pushouts]].

>[!definition]
>We define $\left\|A\sqcup^CB\right\|_{0}$ to be the **set pushout** of $f$ and $g$.
