# Homotopy Inductive Types
---
**Homotopy Inductive Types** are a generalization of [[Inductive Types]], where they loosen the condition for defining functions to propositional equality. For instance, consider [[Natural Numbers in Type Theory]] and replace all the $\equiv$ with $=$. 

We do loose that fact that all definitions now only satisfy propositional equality, but the benefit is that all [[Inductive Types are Initial Algebras|Homotopy Initial Algebra]] is a **Homotopy Inductive Types**.

This also lets us state the properties of inductive types inside homotopy type theory, this one can define a type of all natural numbers.
