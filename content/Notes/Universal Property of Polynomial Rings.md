# Universal Property of Polynomial Rings
---
Consider the forgetful functor $U: \text{CRing} \to \text{Set}$, which sends a ring to its underlying set.

Now given a set $X = \{ x_{1},x_{2} \dots x_{n} \}$ consider the functor $F:\text{CRing} \to \text{Set}$ defined as $R \mapsto X \to UR$.

This functor is represented by the the object $\mathbb{Z}[x_{1},x_{2}\dots x_{n}]$ because given any function $X \to \text{UR}$ there is a unique function $\mathbb{Z}[X] \to R$ which sends element of $X$ to the same place.

Hence $(\mathbb{Z}[x_{1},\dots x_{n}], x_{n} \mapsto x_{n})$ form a universal property.
