# Neighborhood
---
>[!definition] Distance
>The distance $d_{\mathfrak A}(x, y)$ is the length of the shortest path on the [[Gaifman Graph]] of $\mathfrak A$. If there no such path then $d_{\mathfrak A} = \infty$.

Given the above definition of distance, one can define a neighborhood  as follows:
>[!definition]
>The radius $r$ ball around $\vec{a} = (a_{1}, \dots , a_{n}) \in A^n$ is the set 
>$$B_{r}^\mathfrak A (\vec{a}) = \{ b \in A\quad |\quad d_{\mathfrak A}(\vec{a}, b) \leq r \}$$
>The $r$-neighborhood of $\vec{ a}$ in $\frak A$ is the $\sigma_{n}$-structure $N_{r}^\mathfrak A(\vec{ a})$ where:
>- The universe is $B_{r}^\mathfrak A(\vec{a})$
>- each $k$-ary relation $R$ is interpreted as $R^\mathfrak A$ restricted to $B_{r}^\mathfrak A (\vec{a})$
>- $n$ additional constants interpreted as $a_{1}, \dots a_{n}$
