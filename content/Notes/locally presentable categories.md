# locally presentable categories
---
>[!definition]
>Let $\kappa$ be a [[Regular Cardinal]]. A [[Small Categories|locally small category]] $C$ is called **locally $\kappa$ presentable** if it is cocomplete and if it has a set of objects $S$ so that:
>- Every object in $C$ can be written as a colimit diagram valued in the subcategory spanned by objects in $S$.
>- For each object $s\in S$, the functor $C(s, -):C\to\text{Set}$ preserves $k$-[[Filtered Category|filtered colimits]].

A functor between locally $\kappa$-presentable categories is **accessible** if it preserves the $k$-filtered colimits.
