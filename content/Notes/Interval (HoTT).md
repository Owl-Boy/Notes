# Interval
---

>[!definition]
>We denote the **Interval** $I$ as the [[Higher Inductive Types]] generated by:
>- A point $0_{I}:I$
>- A point $1_{I}:I$
>- a path $\text{seg}:0_{I}=1_{I}$.

>[!note] Recursion Principle
>The recursion principle for the interval says that given a type $B$ along with:
>- a point $b_{0}:B$
>- a point $b_{1}:B$
>- a path $s:b_{0}=b_{1}$
>
>There is a function $f:\prod_{x:I}P(x)$ such that $f(0_{I})\equiv b_{0}$, $f(1_{I})\equiv b_{1}$ and $f(\text{seg})=s$.

>[!note] Induction Principle
>The Induction Principle for the interval says that given $P:I\to\cal U$ along with:
>- a point $b_{0}:P(0_{L})$
>- a point $b_{1}:P(1_{L})$ and
>- a path $s:b_{0}=_{\text{seg}}^Pb_{1}$
>
>Then there is a function $f:\prod_{x:I}P(x)$ such that $f(0_{I})\equiv b_{0}$, $f(1_{I})\equiv b_{1}$ and $\text{apd}_{f}(\text{seg})=s$.
