# Data Complexity of a Logic
---
**Data Complexity** talks about of a logic $\mathcal{L}$ talks about how difficult it is check if a given model satisfies a sentence of the logic, here the complexity is only depended on the model and is agnostic of the sentences that are used for model checking, so it is defined as follows:

>[!definition]
>The data complexity of $\mathcal{L}$ is $\mathcal K$ if for every sentence $\Phi$ in $\mathcal{L}$, the language 
>$$
>\{ \text{enc}(\mathfrak A)\; | \; \mathfrak A \vDash \Phi \}
>$$
>belongs to $\cal K$.
