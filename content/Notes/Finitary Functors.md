# Finitary Functors
---
>[!definition]
>A functor $F$ is called **finitary** if it preserves all [[Filtered Category|filtered colimits]].

In particular a monad $T:C\to C$ is called finitary if it preserves all filtered colimits in $C$. If a right adjoint in finitary, then so is the monad is left adjoints preserve all colimits.
