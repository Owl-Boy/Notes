# Residuals using Longest Common Prefixes
---
When discussing [[Algebraic Classification of Recognizable functions]] there was a section about a recognizable function being in a finitely generated stable module. 

One can compute a residual using the following manner:
$$
u^{-1}f(w) = \left(\bigwedge f(uA^*)\right)^{-1} f(uw)
$$
