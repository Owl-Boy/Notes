# Weak Function Extensionality
---
>[!definition]
>**Weak Function Extensionality** states that there is a function of type 
>$$
>\left( \prod_{a:A}\text{is-Contr}(P(a)) \right) \to \text{is-Contr}\left( \prod_{a:A}P(a) \right)
>$$

That is, If for all $a$, $P(a)$ contains exactly 1 element. then product of all $P(a)$ contains exactly $1$ element.
