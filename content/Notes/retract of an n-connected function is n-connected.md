# retract of an n-connected function is n-connected
---
>[!theorem]
>Suppose $g$ is a [[Retracts (HoTT)|retract]] of an $n$-connected function $f$. Then $g$ is $n$-connected.

This is a direct consequence of the lemma in [[Retracts (HoTT)]].
