# Order Invariant FO
---
Order Invariant FO, also denoted as $(\text{FO} + <)_{\text{inv}}$ where the model is equipped with $<$ operator which is interpreted as some total order. 

While this does not fix an ordering, just a presence of a structure is enough to change the expressive power of the logic.

>[!theorem] Theorem (Gurevich)
>There are $(\text{FO} +<)_{\text{inv}}$ queries that are not definable in $\text{FO}$, i.e:
>$$\text{FO} \quad \subsetneq \quad(\text{FO} +<)_{\text{inv}}$$

This is demonstrated by giving an explicit construction: The number of atoms being even in a boolean algebra is definable is $(\text{FO}+<)_{\text{inv}}$ but not in $\text{FO}$, as discussed here [[Even Atoms in Boolean Algebras]]
