# Types of Modules
---
Some of the special types of modules are defined below
- *Free*: A module is said to be free if it has a *"basis"*, i.e there exists a set $X$ such that all elements of the module are linear combinations of $X$. This will be isomorphic to $|X|$ many direct sums of $R$
	- *Finitely Generated*: These are a special case of *free modules* where the generating set is finite.
	- A special case of *Finitely Generated Modules* are *Cyclic Modules* which are modules generated by 1 element.
