# Letter Number Game
---
The **Letter Number Game** is a game played between 2 players, a letter player and a number player.

The Letter player gets to pick one of 4 letters in their turn $[a,b,c,d]$ and the number player has to respond by picking one of the following numbers $[1,2,3,4]$.
 
A game is winning for the number player, if the largest number returned infinitely many times is the same as the number of letters seen infinitely many times.

Turns out, the number player has a winning strategy which is fairly straightforward to construct using [[Last Appearance Record]].
