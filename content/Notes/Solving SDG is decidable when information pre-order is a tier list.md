# Solving SDG is decidable when information pre-order is a tier list

---

The idea behind this construction will be as follows:
- We will show that all players that have an equivalent amount of information can work together like 1 player.
- If the players form a linear order, then the last player is redundant.

> [!NOTE]
> The first point lets us convert to an arena where players are linearly ordered. The second point lets us have an arena with just one player, thus the problem is reduced to model checking of LTL formula.
