# Torus 
---
The torus $T^2$ can be generated by
- A point $b:T^2$
- A path $p:b=b$
- Another path $q:b=b$, and
- a 2-path $t:p\cdot q=q\cdot p$

The simplest way to see that this is a torus is to start with the following rectangle:
![[Pasted image 20250723003759.png|150]]
the path $t:p \cdot q=r\cdot s$. Now we identify $r$ with $q$ and $s$ with $p$. 

Look at [[CW Complex (HoTT)]] for explanation of the induction principle.

We define the induction principle of the Torus as follows:
>[!note] Induction Principle
>Given  a type family $P:T^2 \to\cal U$ and the following data:
>- A point $a:P(b)$
>- A path $p':a=^P_{p}a$
>- A path $q':a=^P_{q}a$
>- a $2-$path $t'$ between the composites $p'\cdot q'$ and $q' \cdot p'$ laying over $t$ as defined in [[CW Complex (HoTT)]]
