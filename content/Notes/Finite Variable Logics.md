# Finite Variable Logics
---
>[!definition]
>The class of $\text{FO}$ restricted to use at most $k$ variables is given by $\text{FO}^k$. The class of $\mathcal{L}_{\infty, \omega}$ restricted to use at most $k$ variables is called $\mathcal{L}_{\infty,\omega}^k$ and we define 
>$$
>\mathcal{L}_{\infty,\omega}^\omega  = \bigcup_{k\in \mathbb{N}} \mathcal{L}^k_{\infty,\omega}
>$$
>This logic descrives the set of formulae that have finitely many variables.
>We can define quantifier ranks for this the same as $FO$ and take supermum to define quantifier rank for infinitary connectives.
