# Finite Type Algebra
---
A **Finite Type Algebra** is an [[Free Algebra]], that is generated from a finite set. This will always be a [[Modules|Module]] but will not necessarily be a finitely generated module.

>[!example]
>The polynomial ring $R[x]$ is a finite-type module, but not a finitely generated module.

The above example can be generated as a module from a singleton set $\{ x \}$. On the other hand, it needs to be generated by the set $\{1,x,x^2\dots\}$.
