# If $C$ is complete and co-complete, so are $C/c$ and $c / C$ for any $c\in\text{ob } C$
---
The statements are dual. so we prove it for $c /C$. Since forgetful functors strictly create limits and all connected colimits, $C$ being complete implies $c /C$ has all limits and connected colimits. We now need to show that coproducts exist.

But since pushouts exist, we need to show that there is an intial object. Which is just $(c, \text{id})$.
