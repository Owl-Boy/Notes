# Truncation
---
We will now see how [[Propositional Truncation]] can be seen as a special case of a construction that can be made using [[Higher Inductive Types]]. 

Let $A$ be a type, we define the propositional truncation $\|A\|$ to be the higher inductive type generated by:
- $A$ function $|-| : A \to \|A\|$ and
- for each $x, y:\|A\|$ a path $x=y$.

Note that the second condition describes that the type is a [[Mere Propositions]], and can be interpreted as saying that $\|A\|$ is freely generated by a function $A\to\|A\|$ and the fact that its a mere proposition.

The recursion principle for this higher inductive definition is simple.

>[!note] Recursion Principle
>Given a type $B:\cal U$, and:
>- a function  $g:A\to B$, and
>- for any $x, y:B$, a path $x=_{B}y$
>
>Then there exists a function $f:\|A\| \to B$ such that
>- $f(|a|)\equiv g(a)$ for all $a:A$
>- for any $x,y:A$, the function $\text{ap}_{f}$ takes the specified path $x=y$ in $\|A\|$ to the specified path $f(x)=f(y)$ (propositionally).

And the induction principle says that given any $B:\|A\|\to\cal U$ together with.
- a function $g:\prod_{a:A}B(|a|)$ and
- for any $x, y:\|A\|$ and $u:B(x)$ and $v:B(x)$, a dependent path $q:u=_{p(x, y)}v$ where $p(x,y)$ is the path generated using the constructor.

there is a function $f:\prod_{x:\|A\|}B(x)$ such that $f(|a|)\equiv g(a)$ for $a:A$

This can be extended to **Set Truncation** in the following way:
>[!definition]
>Given a type $A$ we can create its set truncation $\|A\|_{0}$ using the following:
>- A function $|-|_{0}:A\to \|A\|_{0}$ and
>- For each $x, y:\|A\|_{0}$ and each $p, q:x=y$, a path $p=q$

and the following induction principle
>[!note] Induction Principle
>Given a type family $B:\|A\|_{0}\to\cal U$ together with
>- a function $g:\prod_{a:A}B(|a|_{0})$ and
>- For any $x, y:\|A\|_{0}$ with $z:B(x)$ and $w:B(y)$ and each $p, q:x=y$ with $r:z=_{p}^Pw$ and $s:z=^{P}_{q}w$ and a 2 path $v:r=^{z=^B_{\_}}_{u(x,y,r,s)}z$ where $u(x,y,p,q):p=q$ is obtained from the constructor.
>  
>Then there exists $f:\prod_{x:\|A\|_{0}}$ such that $f(|a|_{0})\equiv g(a)$ for all $a:A$ and $\text{apd}_{f}^2(u(x,y,p,q))$ is the 2-path specified above.
