# Split Exact Sequences
---
>[!definition]
>A **split exact sequence** is a special case of [[Short Exact Sequences]] that is described by the following shape.
>$$
>0 \longrightarrow M_{1}  \longrightarrow M_{1} \oplus M_{2}  \longrightarrow M_{2}  \longrightarrow 0
>$$
