# APX (Complexity Class)
---
>[!definition]
>A problem belongs to the complexity class **APX** If there is a *non-deterministic* machine that can find an approximate solution by a constant factor in *polynomial time*.

Some known problems in the complexity class $\text{APX}$
- [[Max Independent Set]]
- [[Travelling Salesman Problem]] when the distance satisfies the metric axioms.
- [[Token Reconfiguration Problem]]

>[!note]
>The deterministic version of this class is [[PTAS (Complexity Class)]]
