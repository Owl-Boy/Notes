# Kernel and Cokernels in R-Mod
---
>[!theorem]
>The following holds:
>- [[Kernels and Cokernels]] exist
>- $\varphi$ is a monomorphism iff $\text{ker}(\varphi)$ is trivial iff the set function $\varphi$ is an injection
>- $\varphi$ is an epimorphism iff $\text{coker}(\varphi)$ is trivial iff the set function $\varphi$ is a surjection.

To check this, one only needs to verify that $\text{ker}(\varphi)$ is defined in the usual manner. and $\text{coker}(\varphi):\equiv \frac{N}{\text{im}(\varphi)}$. The proof of implications are also triviai.
