# Rational Series
---
>[!definition]
>**Rational Series** form the smallest family of series 
>- Contain polynomials
>- Closed under
>	- left/right scalar multiplication
>	- addition
>	- cauchy product
>	- kleene star (of proper series)

>[!example]
>- $((2a)^* (b+3b^2))^* = 1 + b + 4b^2 + 2ab+8ab^2+4a^2b\dots$
>- If we write the expression $X=AX+B$ we can get that $X = A^*B$ as $A^*$ is similar in some sense to $\frac{1}{1-A}$. Where all such variables represent languages.
