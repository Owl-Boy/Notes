#  Set is a topos

- [[Set is Complete and Cocomplete]] shows that set has finite limits and colimits.
- Set has exponential objects, which are give by the hom-sets themselves.
- The 2 elements set is the sub-object classifier in set.

This is the motivating example of topos theory in general
