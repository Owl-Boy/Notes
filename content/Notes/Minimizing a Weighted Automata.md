# Minimizing a Weighted Automata
---
The Algorithm for Minimizing a Weighted Automata is very simple to an algorithm for minimizing a finite state automata, the algorithm for finite state automata goes as follows:
- Reverse
- Reduce
- Reverse
- Reduce.

There is an analogous algorithm for Reduce, this is discussed in [[Reducing a Weighted Automata]].

The analogue for reversing and automata in [[Transpose of a Weighted Automata]]. With these two, we have the following algorithm:
- Transpose
- Reduce
- Transpose
- Reduce
