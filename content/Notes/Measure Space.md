# Measure Space
---
A measure space is the tuple $\langle \Omega, \mathcal A, \mu \rangle$ where
- $\Omega$ is the set on which the measure is to be defined.
- $\mathcal{A}$ is a [[Sigma Field]] over $\Omega$
- $\mu$ is a function from $\Omega$ to $\mathbb{R}$

$\mu$ is the function that assigns measures to subsets of the universe and it satisfies the following properties:
- $\mu^{-1}(B) \in \mathcal{A}$ for any [[Borel Sigma Field|Borel Set]] $B$.
- $\mu(A_{1} \sqcup A_{2}\dots )= \mu(A_{1}) + \mu(A_{2}) \dots$ 
- $\mu(\emptyset)$
- $\mu$ is a non-negative function.
