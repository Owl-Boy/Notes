# Continuum Hypothesis
---
>[!theorem] $2^{\aleph_{0}} = \aleph_{1}$

The above is the statement of the continuum hypothesis, the following are some alternative formulations, all of which require choice:
- There is no cardinality strictly between  $\aleph_{0}$ and $2^{\aleph_{0}}$
- Every set of real numbers is either countable or has the same cardinality as $\mathbb{R}$
- Given any set of reals, either the set of integers can be mapped onto it, or it can be mapped onto the set of all reals
- $\forall X \Big[ \exists f\ \forall y \in X\; \exists x \in \mathbb{N}[y=f(x)]\quad\lor\quad \exists g\ \forall y \in \mathbb{R}\; \exists x \in X[y=f(x)]\Big]$
	- This says, given any subset $X$ of $\mathbb{R}$, either $\mathbb{N}$ maps onto $X$ or $X$ maps onto $\mathbb{R}$.
- Same thing with functions instead of sets
	- Let $X$ be a function and we replace $\forall y \in X [\phi]$ we have $\forall y[X(y)=0 \land \phi]$

The last way for writing the hypothesis will be useful because of the axioms system that will be constructed.
