# Refutative and Affirmative Assertions
---
>[!example] 
>Consider the following assertion as my motivating examples
>> My baby has *black* eyes.
>
>along with the following picture of the baby.
>![[Pasted image 20241207170737.png]]
>This happens to be the black and white version of a picture of the baby, hence it is not quite enough to tell whether the assertion is true or false based on just the picture. Thankfully, we are promised a coloured picture of the child so we need not worry about that. In the mean time, we can make guess about how things actually go:
>- Her eyes are actually black
>- Her eyes are really dark green
>- We fail to agree but a colour analyzer will help us decide
>- etc etc.

With that example in mind, given an assertion we can ask
- Under what circumstances can we *affirm* the assertion.
- Under what circumstances can we *refute* the assertion.

>[!example] Example cont.
>We eventually get the coloured pictures and see that the child has black eyes. That is enough to confirm the assertion. But a couple of years ago, when the picture was taken, and the eyes of child were definitely dark brown. 
>That begs the question, when can we say that the eyes are black and when can we not?

The solution to that depends on how we want to deal with the boundary case. Where the truth is cannot be known.

If we assume the boundary case to be true. Any observation that tells us that the assertion is false is a definite *refutation*. If we assume the boundary case to be false. Any observation that says the assertion is true is irrefutable. This leads us to 2 definitions
- *Affirmative* : A statement is true exactly when it can be proven to be true.
- *Refutative*: A statement is false exactly when it can be proven to be false.

>[!example] More Examples
>- Some babies have blue eyes ( *affirmative* )
>- All Ravens are black ( *refutative* )
>- A specific person is exactly 6 feet tall ( *refutative* )
