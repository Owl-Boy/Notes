# Initial, Terminal and Zero Objects
---
>[!definition]
>An object $i$ is initial if for every $c\in C$, there is a unique morphism  $i \to c$.
>An object $t$ is terminal if for every $c\in C$. there is a unique morphism $c\to t$.

>[!example]
>- The emtpy set in the category of $\text{Set}$ is an initial object and every singleton is a terminal object
>- In $\text{Top}$, the empty and singleton space are initial and terminal objects.
>- In $\text{Set}_{*}$ any singleton is both a terminal and an initial object.
>- The trivial group is both terminal and initial.
>- The zero ring is the terminal ring, the integers form an initial ring.
>- In there category of field there are no initial and terminal objects
>- An initial object in a pre-order is the global minimum and any terminal object is the global maximum.

>[!definition]
>If an object is both an initial object and a terminal object, we call it a **zero object**.
