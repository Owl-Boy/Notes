# Complexity of First Order Logic
---
To describe complexity of queries for first order logic, we look at the problem of Model checking first order logic.

>[!Question] Model Checking
>Given a sentence $\Phi$ in a logic $\mathcal{L}$, and a finite model $\mathcal M$. The model checking problems asks if $\mathcal M \models \Phi$.

We study 3 notions of complexity about this problem:
